# Roadmap

## Current Phase

Current phase: frontend MVP for static screenshot mockups

Shipped in the current version:

- template-based editor
- screenshot upload
- live preview
- PNG export

## Phase 1: Strong MVP

Goal:

Make the current tool feel complete for single-image screenshot generation.

Planned items:

- App Store and Play Store size presets
- improved text layout options
- more template variations
- better screenshot cropping and positioning
- stronger mobile responsiveness
- export polish and quality controls

## Phase 2: Better Mockup System

Goal:

Move from a simple single poster generator to a more flexible screenshot production tool.

Planned items:

- multiple slides in one project
- reorderable screenshot sets
- template categories
- reusable theme settings
- per-slide overrides
- saved local project drafts

## Phase 3: Advanced Visual Quality

Goal:

Improve the realism and premium feel of outputs.

Planned items:

- hybrid photographic background support
- shadow presets
- better device variations
- richer staging components
- reusable scene metadata and anchors

## Phase 4: 3D and Motion

Goal:

Extend the product beyond flat scene composition into animated showcase assets.

Planned items:

- React Three Fiber integration
- 3D device scenes
- animated camera movement
- multi-frame motion templates
- short promo export workflows

## Phase 5: Product Expansion

Goal:

Turn the tool into a fuller product platform.

Possible items:

- user accounts
- cloud project storage
- billing
- team collaboration
- asset libraries
- shared template marketplace

## Recommended Build Order

The best next implementation order is:

1. store dimension presets
2. multi-slide mockup workflow
3. improved screenshot positioning controls
4. template categorization
5. 3D scene experiments
6. motion export

## Strategic Notes

- keep the core product template-first
- avoid turning the MVP into a full blank-canvas editor too early
- preserve browser-first rendering as long as it remains practical
- add backend complexity only when clear product value demands it
